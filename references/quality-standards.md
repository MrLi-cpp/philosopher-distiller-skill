# Phase 6: 质量标准与验收条件

## 6.1 数据质量指标

| 指标 | 合格标准 | 检测方法 |
|------|---------|---------|
| 去重率 | < 5% 重复内容 | SimHash 相似度 > 0.85 |
| 乱码率 | < 1% 乱码段落 | 符号密度 + 字典覆盖率 |
| 语言纯度 | > 95% 目标语言字符 | Unicode 范围统计 |
| 段落完整性 | 100% 段落以句号/问号/感叹号结尾 | 句末标点检测 |
| 版权合规 | 100% 公版或开放获取 | 来源元数据核查 |
| 二手引用准确率 | > 98% 学者姓名/著作名可在原文中找到 | 字符串匹配 + 模糊匹配 |
| 一手/二手比例 | 符合 `secondary_weight` 设定 | 样本统计 |
| 观点冲突保留率 | 100% 检测到的冲突不被消除 | 冲突检测日志回溯 |

## 6.3 边界情况处理

| 情况 | 处理策略 |
|------|---------|
| 数据源不可达 | 自动降级到次级源 |
| 无公版资源 | 标注版权限制，仅抓取 OA 论文和百科条目 |
| OCR 质量差 | 乱码率 > 20% 标记为"低质量源" |
| 语言不匹配 | 报告中提示，尝试抓取中文研究 |
| 单来源过短 | 清洗后 < 1000 字标记为"样本不足" |
| 二手观点矛盾 | **不消除矛盾**，报告中列出冲突主题 |
| 学者姓名识别错误 | NER 辅助识别，人工复核 Top 10 高频学者 |
| 版权协议冲突 | SEP 为 CC BY-NC-ND，不可商用；计划中警告并过滤 |
